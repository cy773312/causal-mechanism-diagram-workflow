# Step 2：因果机制审计（Audit）

## 概述

核心任务：**对箭头机制链逐条审查，识别因果诊断风险、变量位置错误和缺失问题。**

审计不是"找茬"，而是用方法论框架系统性地暴露机制推理中的薄弱环节，为后续绘图和修改提供依据。

审计分为三个模块：

- **模块 A（因果诊断三问）**：对每条箭头 Xi→Xj 逐一提问，评估因果断言的置信度
- **模块 B（变量位置审查）**：检查每个因素在图中放置的位置是否与其理论角色匹配
- **模块 C（缺失诊断）**：识别机制推理中的系统性缺失，判断其严重程度

操作原则：

- **不修改机制结构**——审计只诊断，不修改。所有改动留到 Step 5 人工修改
- **不新增变量**——审计只能指出"此处可能存在缺失"，不能凭猜测填补
- **区分"画进图里"与"文字交代"**——并非所有风险都需要入图；有些在文字中说明即可

---

## 理论基础

### 为什么"箭头"不等于"因果"

因果图示（包括 Mermaid 图）是**认识论工具**，是对机制的简化表达，而非机制本身（叶成城，2025）。箭头代表研究者相信存在因果动力，但这一信念需要接受方法论检验。

以下三条审计的提问来源于因果推断的经典方法论框架：

| 问题 | 对应威胁 | 来源 |
|------|---------|------|
| 问一：是否存在第三变量（Confounding）？ | 虚假相关性：Z 同时驱动 Xi 和 Xj，误以为 Xi→Xj | 标准因果推断 |
| 问二：是否存在反向因果（Reverse Causality）？ | 干涉性：实际是 Xj 选择或影响了 Xi，而非因果方向 | 双向因果 | 
| 问三：移除该节点后链是否仍然成立（Robustness）？ | 可还原性：节点是必要环节还是可有可无的填充 | 机制可还原性（叶成城） |

这三问覆盖了因果推断中最常见也最容易被忽视的三种威胁。审计的目标不是证明箭头"对"或"错"，而是**标注风险等级，让作者自己对置信度做最终判断**。

## 输入格式

来自 Step 1 的完整输出，包含：

- **主链**（X → M1 → M2 → ... → Y，含分叉或并行路径）
- **节点说明**（每个节点的 4-10 字概念 + 解释）
- **箭头说明**（每条箭头对应的因果动力解释）
- **暂不放入主链的因素**（背景条件、调节变量、替代解释、可能缺失节点）
- **转化备注**（转化中的主要判断和注意事项）

> **若输入不完整**：请在审计报告的备注中说明当前分析的局限（例如："Step 1 输出中未提供箭头说明，以下审计基于主链结构进行，省略了箭头层面的因果诊断"）。

## 模块 A：因果诊断三问

对主链中的**每一条箭头** Xi→Xj 依次提出三个问题。

### 问一：第三变量（Confounding）

**提问**：是否存在某个变量 Z，既驱动 Xi 发生变化，也驱动 Xj 发生变化，导致 Xi→Xj 看起来成立但实际上是虚假因果？

**识别信号**：

- 文本中提到的外部因素可能同时影响两端
- 研究设计中未控制的共同原因
- 理论上有理由认为 Xi 和 Xj 共享上层驱动因素

**风险等级**：

| 等级 | 含义 |
|------|------|
| 高 | 存在明显的、已知的第三变量，且当前研究无法控制 |
| 中 | 存在潜在的第三变量，但可通过研究设计部分控制 |
| 低 | 无明显第三变量，或已知第三变量已被控制 |

### 问二：反向因果（Reverse Causality）

**提问**：是否存在 Xj 比 Xi 先发生，或者 Xj 反过来"选择"了 Xi 的情况？

**识别信号**：

- Xj 在时间上可能先于 Xi
- Xj 是 Xi 的选择标准或筛选条件
- 存在"自我选择""幸存者偏差"等机制

**风险等级**：

| 等级 | 含义 |
|------|------|
| 高 | 强烈理由怀疑因果方向相反，或存在双向因果且无法辨识 |
| 中 | 反向因果在理论上可能，但在当前情境下可能性有限 |
| 低 | 时间顺序清晰，Xj 在理论上不可能先于 Xi 发生 |

### 问三：稳健性（Robustness）

**提问**：如果从因果链中移除该节点，整条链是否仍然成立？Xi 能否直接导致 Xj+1？

**识别信号**：

- 该节点似乎是"填充"性质的中间环节
- 移除后链的逻辑连贯性未受显著影响
- 该节点实际上是其他环节的附带结果而非因果环节

**风险等级**：

| 等级 | 含义 |
|------|------|
| 高 | 移除后链完全不成立，说明该节点是必要环节 |
| 中 | 移除后链的逻辑略有跳跃，但因果方向仍可理解 |
| 低 | 移除后链仍然成立，说明该节点冗余或不过渡实质因果 |

> 注意：稳健性的"风险"方向与问一、问二不同。问一、问二的"高风险"意味着箭头因果性弱；问三的"高"风险意味着节点关键（正向信号）。三问综合时需区分。

### 综合判断

| 综合等级 | 判定标准 | 含义 |
|----------|----------|------|
| **强** | 三问均低风险 | 箭头因果性可靠，画进图里无争议 |
| **中** | 一项中或高风险 | 箭头存在一定风险，需要补充说明或在图中标记 |
| **弱** | 两项以上中/高风险，或任一项高风险 | 箭头因果性存疑，建议在文字中详细讨论 |

### 输出格式

每条箭头生成一条诊断表记录，格式如下：

```
| 箭头 | 第三变量 | 反向因果 | 稳健性 | 综合 |
|------|---------|---------|--------|------|
| X→M1 | 中：... | 低：... | 高（正向）：... | 中 |
| M1→M2 | 低 | 低 | 高（正向） | 强 |
| M2→Y | 高：... | 中：... | 中：... | 弱 |
```

输出整体四项结论：

1. **最稳健的箭头**（综合等级"强"的箭头，作图时无需额外标记）
2. **最薄弱的箭头**（综合等级"弱"的箭头，需要在图中标记或在文字中说明）
3. **必须画进图里的审计信息**（如确认的第三变量需要加入图中作为背景条件）
4. **只需在文字中交代的信息**（如潜在反向因果风险较低，在文字中说明即可）

## 模块 B：变量位置审查

### 六类位置

在因果机制图中，每个因素可能处于以下六类位置之一：

| 位置类型 | 含义 | 图中表示方式 |
|----------|------|-------------|
| **1. 主链节点** | 核心因果链上的传导环节 | 主箭头线上方框 |
| **2. 图外（背景条件）** | 机制成立所需的外部前提或范围条件 | 图框外标注或注脚 |
| **3. 箭头旁（调节变量）** | 影响机制强弱、方向或速度因素 | 箭头旁的标记或注释 |
| **4. 旁支（替代解释）** | 作者考虑但排除的其他因果路径 | 虚线箭头或单独旁路标注 |
| **5. 问号节点** | 审计认为可能存在但暂未确认的因素 | 虚线框 + 问号标记 |
| **6. 只在文字中交代** | 重要性不足以入图，但在正文中说明即可 | 不入图 |

### 操作流程

1. **列出所有因素**：从 Step 1 的输出中提取所有因素（主链节点 + 暂不放入主链的因素）
2. **判断当前分类**：逐一检查 Step 1 给每个因素分配的分类是否准确
3. **建议调整**：如发现分类不当，提出调整建议并说明理由

### 重点检查项

| 常见错误 | 问题 | 纠正建议 |
|----------|------|---------|
| 调节变量被放入主链 | 调节变量影响机制强度，但不参与因果传递 | 移出主链，标注在对应箭头旁 |
| 背景条件被画成旁支 | 背景条件是先决条件，不是竞争性解释 | 移至图外标注或文字说明 |
| 替代解释未入图也未文字交代 | 读者无法判断作者是否考虑了竞争性解释 | 在文字中明确说明，或标为旁支 |
| 问号节点未被标记 | 审计发现的缺失未以任何方式表达 | 加虚线框和问号标记 |

### 输出格式

#### 位置审查表

```
| 因素 | 当前分类 | 建议位置 | 理由 |
|------|---------|---------|------|
| （因素名称） | （Step 1 分类） | （建议调整后的位置） | （方法论依据） |
```

#### 图形布局建议

对 Mermaid 图的布局提出结构性建议，例如：

- "背景条件应移至图框外左上角"
- "调节变量应标注在 X→M1 箭头旁而非作为单独节点"
- "旁支替代解释用虚线箭头表示"

## 模块 C：缺失诊断

### 六类缺失

| 缺失类型 | 含义 | 典型表现 |
|----------|------|---------|
| **1. 行动者缺失** | 机制中缺少关键行动者，机制"无人执行" | 仅描述过程，未说明谁在执行 |
| **2. 负案例缺失** | 缺少"如果没发生会怎样"的反面比较 | 仅有正向路径，未考虑阻断条件 |
| **3. 时间顺序缺失** | 机制的时间性未被充分表达 | 多个环节同时发生，时序模糊 |
| **4. 替代路径缺失** | 可能存在其他路径通往相同结果 | 主链单一，未考虑其他可能路径 |
| **5. 数据来源缺失** | 机制推断缺乏经验依据 | 纯理论推导，无经验支持说明 |
| **6. 反事实缺失** | 缺少"如果 X 不同会怎样"的推理 | 未考虑反事实情景 |

### 严重程度分类

采用缺失数据分类框架来评估缺失的严重程度：

| 程度 | 含义 | 处理方式 |
|------|------|---------|
| **MCAR（完全随机缺失）** | 缺失与机制本身无关，纯粹是表述不完整 | 补充说明即可，不影响因果推断 |
| **MAR（可通过设计补救）** | 缺失虽存在，但可通过研究设计或补充数据补救 | 需要在文字中说明补救方案 |
| **MNAR（非随机缺失，潜在硬伤）** | 缺失与因果推断本身相关，无法通过简单设计补救 | 需要认真评估是否影响核心结论 |

### 硬伤判断

**硬伤标准**：若该缺失会导致研究者**系统性高估或低估因果效应**，且**无法通过研究设计或数据补充弥补**，则判定为硬伤。

例如：

- 行动者缺失导致"机制"变成空转的过程描述 → 通常可以补充，不构成硬伤
- 负案例缺失导致只看到成功路径而忽略失败路径 → 如果数据本身有幸存者偏差，可能构成硬伤
- 反事实缺失导致无法推断因果方向 → 如果无法设计反事实比较，可能构成硬伤

### 输出格式

#### 缺失表

```
| 缺失类型 | 具体表现 | 严重程度 | 是否硬伤 | 补救办法 |
|----------|---------|---------|---------|---------|
| （类型） | （在本文中的具体表现） | MCAR/MAR/MNAR | 是/否 | （建议的补救措施） |
```

#### 三项总结

1. **最严重的缺失**：哪个缺失对因果推断影响最大？
2. **最容易补救的缺失**：哪个缺失只需在文字中补充即可？
3. **需要额外研究的缺失**：哪个缺失需要进一步收集数据或文献支撑？

## 常见陷阱

| 错误 | 正确做法 |
|------|----------|
| **把背景条件当作第三变量** | 背景条件是先决条件（if-then），第三变量是对因果方向的竞争性解释（Z→X, Z→Y）。审计前需先明确区分。 |
| **模块 A 全部低风险** | 如果每条箭头都"没问题"，说明审计不够认真。每条箭头有不同程度的风险，坦诚面对才体现方法论自觉。 |
| **模块 C 全部 MNAR** | 并非所有缺失都是硬伤。多数缺失属于 MCAR 或 MAR，只需合理说明即可。一律标 MNAR 会降低审计可信度。 |
| **替用户做取舍** | 审计只标注风险、建议位置、说明缺失。是否为某条箭头补充数据、是否调整变量位置——最终判断由用户做出。 |
| **把"文字交代"当回避出口** | "在文字中交代"不是解决所有风险的魔法答案。对于高风险箭头，文字交代必须具体说明风险原因和作者的应对策略。 |
| **忽略箭头说明的内容** | 箭头说明（为什么 X 推动 M1）是因果诊断的重要依据。如果 Step 1 未提供完整的箭头说明，模块 A 的诊断将缺乏基础。 |

## 示例（制裁案例）

以下展示对制裁案例箭头骨架的审计结果。完整案例说明见 [examples/sanctions-case.md](../examples/sanctions-case.md)。

**输入骨架**（来自 Step 1）：

```
主链：经济制裁实施 → 精英寻租机会增加 → 政权资源控制强化 → 威权政权巩固
背景条件：威权体制已初步建立
调节变量：制裁强度与范围；反对派原有组织能力
替代解释：制裁强度不足；国际制裁协调失败
```

### 模块 A 诊断

| 箭头 | 第三变量 | 反向因果 | 稳健性 | 综合 |
|------|---------|---------|--------|------|
| 经济制裁实施 → 精英寻租机会增加 | 中：国际制裁协调失败可能同时影响制裁效果和寻租空间 | 低 | 高（正向） | 中 |
| 精英寻租机会增加 → 政权资源控制强化 | 低 | 低 | 高（正向） | 强 |
| 政权资源控制强化 → 威权政权巩固 | 低 | 中：威权巩固也可能反过来促进资源控制 | 高（正向） | 中 |

**四项结论**：

1. **最稳健的箭头**：精英寻租机会增加 → 政权资源控制强化（三问均低风险）
2. **最薄弱的箭头**：无"弱"等级箭头，但"经济制裁→寻租"和"资源控制→威权巩固"均为"中"等级，需在文字中说明
3. **必须画进图里的审计信息**：国际制裁协调失败作为潜在第三变量，建议在图外标注
4. **只需在文字中交代的信息**：反向因果风险（威权巩固→资源控制）在文字中讨论即可

### 模块 B 布局建议

- 背景条件"威权体制初步建立"应置于图框外左上角
- 调节变量"制裁强度与范围"标注在第一条箭头旁
- 调节变量"反对派原有组织能力"标注在最后一条箭头旁
- 替代解释"制裁强度不足"以旁支虚线箭头表示

### 模块 C 缺失总结

| 缺失类型 | 具体表现 | 严重程度 | 是否硬伤 | 补救办法 |
|----------|---------|---------|---------|---------|
| 行动者缺失 | 谁在执行"资源控制强化"？（国家机构？精英群体？） | MAR | 否 | 在节点说明中补充行动者 |
| 负案例缺失 | 只有制裁→威权巩固的正向路径，没有考虑制裁导致政权崩溃的路径 | MNAR | 是 | 需在文字中说明何时/何条件下制裁会适得其反 |

**三项总结**：

1. **最严重的缺失**：负案例缺失——只考虑了正向路径，忽略了制裁可能反而削弱威权的条件
2. **最容易补救的缺失**：行动者缺失——在节点说明中补充即可
3. **需要额外研究的缺失**：负案例路径需要额外文献或案例支持

> 完整走通案例见 [examples/sanctions-case.md](../examples/sanctions-case.md)。
