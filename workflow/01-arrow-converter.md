# Step 1：从自然语言到箭头形式（Arrow Converter）

## 概述

核心任务：**将用户的自然语言机制段落，转化为结构清晰、可用于绘图的箭头骨架。**

操作原则：
- **不评价机制对错**，不新增用户未提及的变量
- **只做结构性转化**，从文字中提炼已有逻辑
- **区分主链与辅助因素**，避免把所有内容塞进同一条链
- **每个节点 4–10 字**，每条箭头配一句话解释

---

## 理论基础

### 机制的本质

因果机制是"**驱动特定类型系统状态变化的动力性过程**"（叶成城，2025）。它不是单纯的叙事，也不是变量之间的统计关联，而是解释"为什么 X 会导致 Y"的中间动力过程。

**核心公式**：原因 X → 通过机制 M → 结果 Y

更准确的逻辑：原因 X **通过机制 M 干预了** Y 的状态变化（而非 M 本身就是 Y 的原因）。

### 需要识别的成分类型

| 成分 | 含义 | 识别方式 |
|------|------|----------|
| **X（原因/自变量）** | 触发机制的初始条件或驱动因素 | 通常是独立变化的核心解释变量 |
| **M1/M2/M3（中介机制节点）** | 机制链中的传导环节；是**动力性过程**，不是中介变量 | 含有"导致""引发""促使""进而""从而"等连接词 |
| **Y（结果/因变量）** | 机制链最终驱动的状态变化 | 通常是作者试图解释的现象 |
| **背景条件** | 机制成立所需的范围条件，不在主链中流动 | 含有"在……前提下""只有当……""以……为条件" |
| **调节变量** | 加速/延缓/强化/抑制机制效果的辅助因素 | 含有"但如果""当……时更强""受到……影响" |
| **替代解释** | 用户文本中提及但作者试图排除的其他解释 | 含有"不同于""并非因为""而非" |

### 关键区分

- **机制 ≠ 中介变量**：机制是过程，不是可以直接测量的变量节点。但为了表达为箭头形式，必须把过程**节点化**（概念化为可命名的阶段）。
- **主链 ≠ 完整叙事**：主链只保留核心因果动力；背景条件、调节变量、替代解释单独列出。
- **"A→B→C"是机制模型，不是机制本身**：箭头图示是认识论工具，是对本体论机制的近似表达。

---

## 操作步骤

### Step 1.1：通读全文，定位结构

阅读用户提供的机制段落，找出：
1. 作者**想解释什么**（→ 这是 Y）
2. 作者**认为什么在驱动 Y**（→ 这是 X）
3. X 到 Y 之间**经历了哪些过程/阶段**（→ 这是 M1/M2/…）
4. 有哪些**附加条件**：范围限定、调节因素、作者排除的解释

### Step 1.2：提炼主链

从文字中提炼**最精简的核心因果链**，用箭头连接：

```
X → M1 → M2 → … → Y
```

要求：
- 每个节点 4–10 字，使用名词短语（如"财富重组与积累"而非"财富积累了很多"）
- 箭头之间的逻辑必须是**因果性**的（A 导致 B），而非时间性（A 之后 B）或描述性（A 和 B 一起发生）
- 若机制中有**分叉**（两条并行路径同时驱动 Y），用以下格式表达：

```
X → M1a → Y
      ↘ M1b → Y
```

### Step 1.3：处理辅助成分

将以下成分从主链中**剥离**，单独列出：
- **背景条件**：机制成立的先决条件（非主链节点）
- **调节变量**：影响机制强弱/速度的因素（可附在对应箭头旁）
- **替代解释**：用户文本提及但排除的解释（说明为何不放入主链）
- **可能缺失节点**：转化过程中发现的逻辑"断裂"处（不要填补，只标记）

---

## 输出模板

```
【研究问题】
（复述用户的研究问题，一句话）

【主链】
X → M1 → M2 → Y
（如有分叉或并行路径，在此说明）

【节点说明】
- X：（4–10字概念 + 一句解释）
- M1：（4–10字概念 + 一句解释）
- M2：（4–10字概念 + 一句解释）
- Y：（4–10字概念 + 一句解释）

【箭头说明】
- X → M1：（一句话解释此箭头代表的机制动力：X通过何种方式推动M1？）
- M1 → M2：（一句话）
- M2 → Y：（一句话）

【暂不放入主链的因素】
- 背景条件：（哪些条件必须成立，机制才能启动？）
- 调节变量：（哪些因素影响机制的强弱或速度？）
- 替代解释：（用户文字中提及了哪些竞争性解释？）
- 可能缺失节点：（转化过程中发现哪些逻辑跳跃或断裂？仅标记，不填补）

【转化备注】
（说明转化中的主要判断：哪些措辞被节点化？哪些内容被移出主链？）
```

---

## 常见陷阱

| 错误 | 正确做法 |
|------|----------|
| 把"背景条件"放入主链（如把"威权体制"当作 M1） | 背景条件单独列出，不进主链 |
| 把时间顺序当因果链（"首先 A，然后 B"） | 检查是否真的存在 A→B 的因果动力 |
| 节点过长（超过 10 字，像句子） | 压缩为名词短语，必要时放入节点说明 |
| 箭头说明重复节点文字 | 说明**为什么/通过什么动力** M1 推动 M2 |
| 新增用户未提及的变量 | 严禁，只能标记为"可能缺失节点" |
| 把"效应"当机制（如直接写"马太效应"为节点） | 效应是结果模式，需要把它背后的动力过程节点化 |

---

## 处理复杂情况

### 多条并行机制

```
主链A（路径名）：X → Ma1 → Ma2 → Y
主链B（路径名）：X → Mb1 → Mb2 → Y
```

### 宏-微观-宏观层级（科尔曼船）

```
XM（宏观原因）→ Xm（微观条件）→ Ym（微观行动）→ YM（宏观结果）
```

### 规范判断或政策建议

规范判断（"应该""必须"）不能作为机制节点；政策建议可视为"干预变量"，单独列出。

---

## 示例（制裁案例）

**输入**（节选）："经济制裁→稀缺性→精英寻租空间增加→精英利益与政权绑定→政权借外敌叙事集中经济部门控制→资源控制权集中→反对派压制能力增强→威权政权巩固。初始威权程度影响此机制的激活。制裁强度和反对派组织能力调节传导效果。"

**输出骨架**：

```
【主链】
经济制裁实施 → 精英寻租机会增加 → 政权资源控制强化 → 威权政权巩固

【暂不放入主链的因素】
- 背景条件：威权体制已初步建立
- 调节变量：制裁强度与范围；反对派原有组织能力
- 替代解释：制裁强度不足；国际制裁协调失败
- 可能缺失节点：M1→M2之间缺少"中产阶级瓦解"的独立路径
```
