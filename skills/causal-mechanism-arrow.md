# Causal Mechanism Arrow Converter（因果机制箭头转化器）

## 概述

本 skill 的核心任务：**将用户的自然语言机制段落，转化为结构清晰、可用于绘图的箭头骨架**。

操作原则：
- **不评价机制对错**，不新增用户未提及的变量
- **只做结构性转化**，从文字中提炼已有逻辑
- **区分主链与辅助因素**，避免把所有内容塞进同一条链
- **每个节点4–10字**，每条箭头配一句话解释

---

## 理论背景：什么是因果机制（阅读此节以理解转化逻辑）

请先理解以下概念，这直接决定如何识别用户文本中的各类成分：

### 机制的本质
因果机制是"**驱动特定类型系统状态变化的动力性过程**"（叶成城，2025）。它不是单纯的叙事，也不是变量之间的统计关联，而是解释"为什么 X 会导致 Y"的中间动力过程。

**核心公式**：原因 X → 通过机制 M → 结果 Y  
更准确的逻辑：原因 X **通过机制 M 干预了** Y 的状态变化（而非 M 本身就是 Y 的原因）

### 需要识别的成分类型

| 成分 | 含义 | 识别方式 |
|------|------|----------|
| **X（原因/自变量）** | 触发机制的初始条件或驱动因素 | 通常是独立变化的核心解释变量 |
| **M1/M2/M3（中介机制节点）** | 机制链中的传导环节；是**动力性过程**，不是中介变量 | 含有"导致""引发""促使""进而""从而"等连接词 |
| **Y（结果/因变量）** | 机制链最终驱动的状态变化 | 通常是作者试图解释的现象 |
| **背景条件** | 机制成立所需的范围条件，不在主链中流动 | 含有"在……前提下""只有当……""以……为条件" |
| **调节变量** | 加速/延缓/强化/抑制机制效果的辅助因素 | 含有"但如果""当……时更强""受到……影响" |
| **替代解释** | 用户文本中提及但作者试图排除的其他解释 | 含有"不同于""并非因为""而非" |

### 关键区分

- **机制 ≠ 中介变量**：机制是过程，不是可以直接测量的变量节点。但为了表达为箭头形式，必须把过程**节点化**（概念化为可命名的阶段）
- **主链 ≠ 完整叙事**：主链只保留核心因果动力；背景条件、调节变量、替代解释单独列出
- **"A→B→C"是机制模型，不是机制本身**：箭头图示是认识论工具，是对本体论机制的近似表达

## 操作步骤

### Step 1：通读全文，定位结构

阅读用户提供的机制段落，找出：
1. 作者**想解释什么**（→ 这是 Y）
2. 作者**认为什么在驱动 Y**（→ 这是 X）
3. X 到 Y 之间**经历了哪些过程/阶段**（→ 这是 M1/M2/…）
4. 有哪些**附加条件**：范围限定、调节因素、作者排除的解释

### Step 2：提炼主链

从文字中提炼**最精简的核心因果链**，用箭头连接：

```
X → M1 → M2 → … → Y
```

要求：
- 每个节点4–10字，使用名词短语（如"财富重组与积累"而非"财富积累了很多"）
- 箭头之间的逻辑必须是**因果性**的（A导致B），而非时间性（A之后B）或描述性（A和B一起发生）
- 若机制中有**分叉**（两条并行路径同时驱动Y），用以下格式表达：

```
X → M1a → Y
      ↘ M1b → Y
```

### Step 3：处理辅助成分

将以下成分从主链中**剥离**，单独列出：
- **背景条件**：机制成立的先决条件（非主链节点）
- **调节变量**：影响机制强弱/速度的因素（可附在对应箭头旁）
- **替代解释**：用户文本提及但排除的解释（说明为何不放入主链）
- **可能缺失节点**：转化过程中发现的逻辑"断裂"处（不要填补，只标记）

### Step 4：撰写输出

严格按照以下模板输出，不省略任何板块：

## 输出模板

```
【研究问题】
（复述用户的研究问题，一句话）

【主链】
X → M1 → M2 → Y

（如有分叉或并行路径，在此说明）

【节点说明】
- X：（4–10字概念 + 一句解释）
- M1：（4–10字概念 + 一句解释）
- M2：（4–10字概念 + 一句解释）
- Y：（4–10字概念 + 一句解释）

【箭头说明】
- X → M1：（一句话解释此箭头代表的机制动力：X通过何种方式推动M1？）
- M1 → M2：（一句话）
- M2 → Y：（一句话）

【暂不放入主链的因素】
- 背景条件：（哪些条件必须成立，机制才能启动？）
- 调节变量：（哪些因素影响机制的强弱或速度？）
- 替代解释：（用户文字中提及了哪些竞争性解释？）
- 可能缺失节点：（转化过程中发现哪些逻辑跳跃或断裂？仅标记，不填补）

【转化备注】
（说明转化中的主要判断：哪些措辞被节点化？哪些内容被移出主链？如有歧义，说明你的处理方式）
```

## 常见陷阱（避免以下错误）

| 错误 | 正确做法 |
|------|----------|
| 把"背景条件"放入主链（如把"威权体制"当作M1） | 背景条件单独列出，不进主链 |
| 把时间顺序当因果链（"首先A，然后B"） | 检查是否真的存在A→B的因果动力 |
| 节点过长（超过10字，像句子） | 压缩为名词短语，必要时放入节点说明 |
| 箭头说明重复节点文字（"M1→M2：M1导致了M2"） | 说明**为什么/通过什么动力** M1 推动 M2 |
| 新增用户未提及的变量 | 严禁，只能标记为"可能缺失节点" |
| 把用户的整个论证都塞进主链（5个以上节点且无分叉） | 识别并移出辅助机制，保持主链精简（通常3–5个节点） |
| 把"效应"当机制（如直接写"马太效应"为节点） | 效应是结果模式，需要把它背后的动力过程节点化 |

## 处理复杂情况

### 情况A：用户文字中有多条并行机制

当文字描述了多条路径同时驱动 Y 时（如曼的四种权力来源），识别并列出：
```
主链A（意识形态路径）：X → Ma1 → Ma2 → Y
主链B（经济路径）：X → Mb1 → Mb2 → Y
```

### 情况B：机制有明显层级（宏观→微观→宏观）

按"科尔曼船"格式识别：
```
XM（宏观原因）→ Xm（微观条件）→ Ym（微观行动）→ YM（宏观结果）
```

### 情况C：用户文字较长，包含多个不同研究问题

只处理用户明确指定的研究问题对应的机制；若无法确定，转化前先向用户确认。

### 情况D：用户文字包含规范判断或政策建议

规范判断（"应该""必须"）不能作为机制节点；政策建议可视为"干预变量"，单独列出。

## 示例（供参考）

**研究问题**：为什么大西洋贸易促进了英国的崛起而未能推动西班牙长期兴盛？

**输入文字**（节选）："大西洋贸易→财富积累与重组→商人阶级壮大→权力斗争与国内制度变迁→崛起成为大国。初始制度类型决定了财富能否促成商人阶级壮大；宗教冲突加剧了内部矛盾。"

**输出**：

```
【主链】
大西洋贸易扩张 → 财富积累与重组 → 商人阶级兴起 → 制度变迁 → 大国崛起

【节点说明】
- X：大西洋贸易扩张 — 殖民贸易带来的跨洲际商业扩张
- M1：财富积累与重组 — 贸易利润流向特定社会阶层
- M2：商人阶级兴起 — 新兴资产阶级积累政治经济资源
- M3：国内制度变迁 — 权力结构重组引发制度安排改变
- Y：大国崛起 — 国家在国际体系中地位上升

【箭头说明】
- X → M1：贸易收益形成财富积累，并改变社会中财富的分配结构
- M1 → M2：积累的财富赋予商人阶级经济独立性，进而增强其政治动员能力
- M2 → M3：壮大的商人阶级挑战传统贵族/王权，推动有利于自身的制度重构
- M3 → Y：制度变迁释放生产力与国家动员能力，国家获得国际竞争优势

【暂不放入主链的因素】
- 背景条件：初始制度类型（攫取型 vs. 包容型）——决定机制能否完整激活
- 调节变量：国家能力——影响制度变迁能否转化为大国崛起的速度和成功率
- 替代解释：纯粹的地理条件决定论——文字中隐含排除
- 可能缺失节点：M2→M3之间缺少"政治联盟形成"的中间环节

【转化备注】
"宗教冲突"被识别为辅助因素（调节变量），加剧矛盾但非主链驱动力。
西班牙/荷兰案例被识别为机制被抑制的比较案例，不进入主链。
```
