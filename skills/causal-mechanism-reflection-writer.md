# Causal Mechanism Reflection Writer（机制图说明与交付思考写作）

## 概述

本 skill 的任务：**将前四个 skill 的过程输出和人工终稿，转化为两类可提交的正文段落**：

1. **机制图终稿说明**：解释终稿图中每类元素的含义与位置逻辑
2. **三个交付思考**：回答机制图作业要求的三个反思问题

操作原则：
- 不改图，不重新审计机制
- 不新增未在前四步中出现的变量或判断
- 正文应是**综合性叙述**，不是对 skill 输出的逐条摘录
- 语言风格：学术中文，简洁，有论证逻辑，段落完整

---

## 输入格式

需要用户提供以下内容（可部分缺失，缺失项在输出中标注"待补充"）：

```
【终稿主链】
（人工确认的最终箭头主链）

【终稿图元素说明】
- 背景条件：（最终放入图中的背景条件）
- 调节变量：（最终标注的调节变量及对应箭头）
- 替代解释：（最终画入图中的替代解释）
- 问号节点：（最终标记的缺失项）
- 最弱环节：（最终标注的最弱箭头）

【修改记录】
（从 causal-mermaid-graph-audit 的修改指令，以及人工做的调整）

【审计关键结论】
（从 causal-mechanism-audit 中摘录：最稳箭头、最弱箭头、最严重缺失）

【研究问题】
（一句话）
```

---

## 两类输出

### 输出一：机制图终稿说明

**目的**：向读者解释终稿图的构成逻辑，说明各类图形元素的含义，以及主要修改决策的依据。

**结构**：

```
第一段：主链说明
  - 复述主链，说明核心因果逻辑
  - 解释主链的读法（从左到右，实线箭头代表因果传导）

第二段：辅助元素说明
  - 背景条件：放在哪里，为什么这样放
  - 调节变量：对应哪条箭头，表达什么
  - 替代解释：指向哪里，为什么画成旁支而非主链
  - 问号节点：标记了什么，为什么用问号

第三段：修改说明
  - 初稿存在哪些问题（来自 graph audit）
  - 做了哪些修改，修改依据是什么
  - 最终图形在哪些地方仍有待进一步实证（来自最弱环节和缺失项）
```

**写作要求**：
- 三段，每段3–5句
- 不使用"如图所示"作为段落起点
- 不重复罗列节点名称，而是说明图形逻辑
- 专业术语（背景条件、调节变量等）直接使用，无需解释

---

### 输出二：三个交付思考

三个思考对应机制图作业的三个反思要求，每个思考独立成段。

**思考一：从文字到箭头，你压缩了什么？**

回答以下问题：
- 原始文字机制中有哪些内容被移出了主链？
- 移出的依据是什么（背景条件、调节变量、替代解释的区分逻辑）？
- 压缩之后，主链保留了什么核心主张？

写作要求：聚焦**一个最重要的压缩决策**展开，不要逐一列举所有移出的内容。

**思考二：哪条箭头最弱？你打算怎么补强？**

回答以下问题：
- 最弱箭头是哪条，三问中哪项风险最高？
- 为什么这条箭头弱（不是泛泛说"需要更多证据"，而是说清楚弱在哪里）？
- 具体打算用什么方法补强（过程追踪、比较案例、档案、访谈、统计等）？

写作要求：聚焦**具体的实证策略**，不泛泛说"需要更多研究"。

**思考三：图里有没有看不见的缺失？缺失是硬伤吗？**

回答以下问题：
- 最重要的缺失是什么（来自 causal-mechanism-audit 模块C）？
- 这个缺失更接近 MCAR、MAR 还是 MNAR？
- 是否构成硬伤？如果是，打算如何处理；如果不是，如何在文字中坦然交代？

写作要求：**坦然面对缺失**，不回避，也不过度渲染。缺失说明是研究诚实性的体现，不是失分项。

## 写作质量标准

**合格段落具备**：
- 有一个明确的论点句（段落第一句）
- 有具体内容支撑（来自前四步的实际输出，不是泛泛的方法论表述）
- 有结论或行动指向（这个判断意味着什么，或接下来要做什么）

**不合格段落的典型表现**：
- 大量使用"本研究认为""本图旨在""如上所述"等空洞表达
- 只重复机制节点名称，没有解释图形逻辑
- 对最弱箭头只说"证据不足"，不说弱在哪里
- 对缺失只说"未来研究可以补充"，不做 MCAR/MAR/MNAR 判断

---

## 常见陷阱

| 错误 | 正确做法 |
|------|---------|
| 把三个思考写成对 skill 输出的摘要 | 思考是**研究者自己的判断**，用第一人称，说明选择和理由 |
| 终稿说明逐一罗列所有节点 | 说明图形逻辑，不是清单 |
| 思考二只写"需要过程追踪" | 说清楚追踪哪个环节、找什么证据、在什么案例中找 |
| 思考三用"局限性"替代缺失诊断 | 直接使用 MCAR/MAR/MNAR 框架，说明缺失性质和严重程度 |
| 三个思考长度悬殊（一个500字，一个50字） | 每个思考150–250字，篇幅大致相当 |

## 示例

**输入**（制裁案例）：

```
【终稿主链】经济制裁实施 → 精英寻租机会增加 → 政权资源控制强化 → 威权政权巩固
【终稿图元素】
- 背景条件：威权体制已初步建立（椭圆，图上方）
- 调节变量：政权宣传能力（标注在M1→M2箭头旁）；制裁强度（标注在X→M1旁）
- 替代解释：无（审计后决定文字交代）
- 问号节点：？中产阶级瓦解（六边形，M1与M2之间）
- 最弱环节：M1→M2（虚线标注）
【修改记录】初稿将政权宣传能力误画为中介节点，修改为调节变量；补充问号节点
【审计关键结论】最稳：M2→Y；最弱：M1→M2（高第三变量风险）；最严重缺失：负案例缺失（MAR）
【研究问题】为什么经济制裁有时反而强化了目标国的威权政权？
```

**输出**：

```
═══════════════════════════════
机制图终稿说明
═══════════════════════════════

本图的主链呈现了经济制裁强化威权政权的核心因果路径：制裁实施通过改变精英的寻租空间，进而强化政权对关键资源部门的控制，最终导致政权巩固。图形从左到右阅读，实线箭头表示主链因果传导，虚线箭头及虚线标注代表辅助性因素。

图中包含四类辅助元素。"威权体制已初步建立"作为背景条件，以椭圆节点标注于主链上方，说明该机制的启动需要一定的制度前提，而非对所有国家普遍成立。"政权宣传能力"与"制裁强度"作为调节变量，分别标注于对应箭头旁，表示它们影响机制传导的速度与强度，但不参与主链因果传导。M1与M2之间标有问号节点"？中产阶级瓦解"，显式标记了一条逻辑上可能存在但尚无充分实证支撑的并行路径。M1→M2箭头以虚线标注，指示该环节为主链中因果证据最薄弱之处。

初稿中政权宣传能力被误置于主链串联序列，经审查后修正为调节变量；问号节点为审查后新增的可视化标记。终稿图在M2→Y环节具有相对充分的理论支撑，而M1→M2环节的因果性尚需进一步的时间顺序证据和案例比较加以确认。

═══════════════════════════════
三个交付思考
═══════════════════════════════

思考一：从文字到箭头，你压缩了什么？

原始文字机制段落中包含一个关键表述：政权通过"外敌威胁叙事"动员民族主义情绪，转移国内矛盾。箭头化过程中，这一叙事动员机制被判断为调节变量而非主链节点——它加速了精英向政权靠拢的过程，但不构成独立的因果传导环节，因为政权在无制裁压力时同样可以激活民族主义叙事。压缩的依据是：调节变量影响机制的强弱，中介节点参与机制的传导，两者逻辑角色不同，不能混用。压缩之后，主链保留的核心主张是：制裁通过改变精英的物质激励结构（而非通过意识形态动员）来强化政权。

思考二：哪条箭头最弱？你打算怎么补强？

M1→M2是主链中因果证据最薄弱的一环。问题不在于证据数量，而在于存在高度可信的第三变量：政权宣传能力可以独立激活"外敌叙事"，进而直接推动资源控制强化，绕过精英寻租这一中间环节。这意味着即使M1不发生，M2也可能出现，从而使M1→M2的因果独立性存疑。补强策略是选择一个制裁程度相近但政权宣传能力显著较弱的对照案例（如某一制裁期间媒体管控松弛的国家），通过过程追踪检验在宣传能力受限的条件下精英寻租是否仍然推动了资源控制集中，以此剥离政权宣传能力的独立效应。

思考三：图里有没有看不见的缺失？缺失是硬伤吗？

当前最重要的缺失是负案例的系统性缺席：三个案例（伊朗、委内瑞拉、缅甸）均为制裁未能削弱政权的情形，图中所呈现的机制仅来自正面证据。这一缺失更接近MAR——缺失是由案例选择策略造成的，而非由机制本身决定，因此可以通过补充负案例加以补救。它目前不构成硬伤，但构成一个明确的研究设计局限：在当前样本下，无法区分"制裁激活了强化机制"与"该类国家在任何外部压力下都倾向于政权巩固"这两种解释。补救方向是纳入至少一个制裁后政权瓦解或显著弱化的案例，以检验机制的条件性。
```
