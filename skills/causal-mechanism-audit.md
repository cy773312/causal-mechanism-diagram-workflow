# Causal Mechanism Audit（因果机制完整审计）

## 概述

本 skill 是因果机制审查的完整工具，整合三个递进模块：

| 模块 | 任务 | 核心问题 |
|------|------|----------|
| **模块A：因果诊断三问** | 逐条箭头检查因果有效性 | 这条箭头真的是因果吗？ |
| **模块B：变量位置审查** | 检查各类因素的图形位置 | 每个变量放对地方了吗？ |
| **模块C：缺失诊断** | 识别机制图中看不见的缺失 | 图里缺了什么，缺失是硬伤吗？ |

**执行原则**：
- 默认三个模块全部执行，按顺序输出
- 若用户指定只做某模块，跳过其余
- 全程不修改机制结构，不新增变量，不替用户做取舍判断
- **所有输出均为审计建议，是否采纳由研究者自行判断。审计发现的"可能缺失节点""替代解释""位置调整"等，不应被后续步骤自动转化为图形元素——研究者有完全的取舍权。**

---

## 理论基础（三个模块的方法论依据）

### 为什么箭头不等于因果？

叶成城（2025）指出，因果图示"A→B→C"只是对机制的**认识论表达**，是模型而非机制本身。从文字到箭头的转化不自动保证因果关系成立。机制性解释的核心要求是：揭示"在特定情境下从原因到结果之间持续展开的因果过程"，并能够"区分真正的因果关系与虚假的相关性"。三个模块分别对应这一要求的不同层面：

- **模块A**：检查每条箭头是否指向真实的因果动力（干涉性）
- **模块B**：检查各类因素在图中的位置是否符合机制的情境性与过程性
- **模块C**：检查机制链的完整性——叶文指出"机制链出现黑箱或解释缺口"是机制性解释失败的核心表现

### 缺失诊断的统计学类比

模块C借用缺失数据分析（missing data analysis）的框架，将机制图中的缺失分类为：
- **MCAR**（完全随机缺失）：缺失与研究本身无系统关联，不影响因果推断
- **MAR**（随机缺失）：缺失可由已知变量解释，可通过研究设计补救
- **MNAR**（非随机缺失）：缺失与被缺失内容本身相关，可能构成硬伤

这一分类并非统计学原意，而是方法论类比，用于判断缺失的严重程度。

## 模块A：因果诊断三问

### A1 三问定义

**第一问：第三变量（Confounding）**
是否存在变量 Z，同时驱动箭头两端，使其共变看起来像因果？

识别信号：
- 箭头两端的节点有共同的上游背景因素
- "暂不放入主链"中的背景条件或调节变量，若单独看也能解释箭头两端的关联
- 箭头说明中的传导逻辑依赖一个未明示的前提

风险等级：**高**（Z 在理论上很可能同时影响两端）/ **中**（Z 存在但路径不明）/ **低**（Z 不存在或可排除）

**第二问：反向因果（Reverse Causality）**
是否可能是 Xj 的变化先发生，反过来引发或选择了 Xi？

识别信号：
- 两端节点在时间上几乎同步发生（难以区分先后）
- Xj 的预期或结果可能激励行为体主动调整 Xi
- 箭头说明中无时间顺序依据

风险等级：**高** / **中** / **低**

**第三问：稳健性（Robustness）**
若移除此节点或此箭头，整条机制链是否仍有解释力？

识别信号：
- 该节点是唯一连接 X 和 Y 的传导点（移除即断链）
- 节点说明实质上是上一节点的换名（同义反复）
- 箭头说明无独立的因果动力，只是重述了节点间的关联

风险等级：**高**（移除即崩塌）/ **中**（大幅削弱）/ **低**（有替代路径）

综合判断标准：
- **强**：三问均低风险
- **中**：一项中/高风险
- **弱**：两项以上中/高风险，或任一项高风险

### A2 输出格式

```

| 箭头 | 第三变量风险 | 反向因果风险 | 稳健性风险 | 综合判断 |
|------|------------|------------|----------|--------|

| M1 → M2 | | | | |

## 模块B：变量位置审查

### B1 六类位置

因果机制图的语法包含六种元素位置，每类因素应放在对应位置：

| 位置 | 含义 | 适合的内容 |
|------|------|-----------|
| **主链节点** | 核心因果传导环节 | 直接参与 X→Y 传导的动力过程 |
| **图外/图上方（背景条件）** | 机制启动的门槛条件 | 不在链中流动、只决定机制是否激活的前提 |
| **箭头旁（调节变量）** | 影响某条箭头的强弱或速度 | 加速/减缓/强化/抑制特定箭头效果的因素 |
| **旁支（替代解释）** | 独立可解释 Y 的竞争路径 | 无法通过背景条件排除的替代机制 |
| **问号节点** | 逻辑断裂处的显式标记 | "可能缺失节点"，确认存在但尚无足够证据 |
| **只在文字中交代** | 不影响图形结构的补充说明 | 可通过案例选择或研究设计排除的替代解释 |

### B2 操作流程

对"暂不放入主链的因素"中的每一项，以及主链节点本身，逐一判断：

1. 当前分类是否准确？（背景条件/调节变量/替代解释/可能缺失节点）
2. 在图中的位置是否与其因果角色匹配？
3. 是否应该调整位置？给出理由。

重点检查以下错位信号：
- 调节变量被放入主链（它影响箭头强度，而非传导路径）
- 背景条件被画成旁支替代解释（两者逻辑截然不同）
- 替代解释被忽略，既未入图也未文字交代（最危险的错位）
- 可能缺失节点被完全不标记（使读者误以为链条完整）

### B3 输出格式

```
【模块B：变量位置审查】

| 因素 | 当前分类 | 建议位置 | 理由 |
|------|--------|--------|------|
| （因素名） | 背景条件/调节变量/替代解释/缺失节点 | 主链/图外/箭头旁/旁支/问号/文字 | （一句话） |

图形布局建议（研究者自行判断是否采纳）：
- 主链保留：
- 图外放置（背景条件）：
- 箭头旁标注（调节变量）：
- 旁支绘制（替代解释）：
- 建议标记的问号节点（研究者自行决定是否保留）：
- 建议仅在文字中交代：

MD记录模板：
## Step 3 变量位置审查
主链保留：
背景条件放置：
调节变量放置：
替代解释放置：
问号缺失节点：
我自己的判断：
```

## 模块C：缺失诊断

### C1 六类缺失

| 缺失类型 | 含义 | 识别信号 |
|----------|------|----------|
| **缺失的行动者** | 机制链中应出现但未出现的施动者 | 某个箭头说明中的"谁"被省略了 |
| **缺失的负案例** | 缺少机制未被激活/被抑制的对照案例 | 只有正面案例，无法检验机制的条件性 |
| **缺失的时间顺序** | 无法确认节点之间的先后关系 | 箭头说明中无时间依据，或节点同步发生 |
| **缺失的替代路径** | 存在绕过某节点直接到达 Y 的路径，图中未呈现 | 替代解释列表中有逻辑上无法排除的竞争机制 |
| **缺失的数据来源** | 某节点或某箭头缺乏可观测的实证支撑 | 节点的状态变化无法被现有材料记录 |
| **缺失的反事实** | 未说明"若 X 不存在，Y 是否仍然发生" | 主链缺乏反事实推理基础 |

### C2 严重程度分类（MCAR/MAR/MNAR）

对每项缺失，判断其性质：

**MCAR（完全随机缺失）**：缺失与研究内容无系统关联，不影响因果推断。例：某年档案恰好缺失，与机制无关。

**MAR（可解释缺失）**：缺失可由已知变量解释，可通过研究设计补救。例：负案例缺失，但可通过案例选择策略弥补。

**MNAR（非随机缺失，潜在硬伤）**：缺失与被缺失内容本身相关，补救成本极高。例：关键行动者的决策过程从未被记录，且其缺席系统性地偏向某个结果。

硬伤判断标准：若该缺失的存在会系统性地高估或低估主链的因果效应，且无法通过现有材料和研究设计弥补，则构成硬伤。

### C3 输出格式

```
【模块C：缺失诊断】

（注：以下诊断基于用户提供的研究范围和材料来源。）

| 缺失类型 | 具体表现 | MCAR/MAR/MNAR | 是否构成硬伤 | 补救办法 |
|----------|--------|--------------|------------|--------|
| 缺失行动者 | | | | |
| 缺失负案例 | | | | |
| 缺失时间顺序 | | | | |
| 缺失替代路径 | | | | |
| 缺失数据来源 | | | | |
| 缺失反事实 | | | | |

三项总结：
1. 最严重的缺失：（说明理由）
2. 是否可能动摇主机制（建议研究者重点评估）：（是/否/部分，说明依据）
3. 建议的标记方式（由研究者决定）：（画问号节点/在图注说明/在正文交代/无需入图）

MD记录模板：
## Step 4 缺失诊断
最重要的看不见缺失：
它更接近：MCAR / MAR / MNAR / 暂无法判断
是否构成硬伤：

## 常见陷阱

| 错误 | 正确做法 |
|------|----------|
| 把"背景条件"认定为第三变量（两者逻辑不同） | 背景条件是门槛，第三变量是共因；背景条件不进主链但也不是混淆变量 |
| 模块A全部判断低风险 | 若三问均低，说明诊断不够深入，需重新审查，尤其检查节点是否存在同义反复 |
| 模块C把所有缺失都标注为MNAR | MNAR是最严重情形，需有明确理由；多数缺失是MAR，可通过研究设计补救 |
| 综合结论替用户做修改决策 | 审计结论指向问题，取舍由研究者判断 |
| 把模块B的"文字交代"当作回避问题的出口 | 凡逻辑上无法排除的替代解释，必须入图（旁支）或研究设计层面处理，不能只靠文字 |
| **将审计发现自动转化为图形元素（审计污染）** | **审计发现的"可能缺失节点""替代路径""位置调整"等是建议而非指令。研究者应逐一判断是否采纳，不采纳的审计发现不应进入后续绘图步骤。这要求研究者主动过滤，而非由大模型自动纳入。** |

## 示例

**输入**：

```
研究问题：为什么经济制裁有时反而强化了目标国的威权政权？

【主链】
经济制裁实施 → 精英寻租机会增加 → 政权资源控制强化 → 威权政权巩固

【箭头说明】
- X → M1：制裁造成稀缺性，使精英通过管控稀缺品获得寻租空间
- M1 → M2：精英利益与政权绑定后，政权借外敌叙事集中经济部门控制
- M2 → Y：资源控制权集中使政权具备更强的压制与忠诚购买能力

【暂不放入主链的因素】
- 背景条件：威权体制已初步建立；可被动员的民族主义情绪存在
- 调节变量：制裁强度与范围；反对派原有组织能力
- 替代解释：制裁强度不足；国际制裁协调失败
- 可能缺失节点：M1→M2之间缺少"中产阶级瓦解"的独立路径

研究对象：中等规模威权国家，2000–2020年，3个案例（伊朗、委内瑞拉、缅甸）
材料来源：政府公报、国际组织报告、精英政治分析文献
```

**输出摘要**：

```
模块A 诊断表：
| 箭头 | 第三变量 | 反向因果 | 稳健性 | 综合 |
|------|--------|--------|------|------|
| X→M1 | 中：初始威权程度可能同时决定制裁概率和精英依附度 | 低：制裁时间上先于寻租机会，顺序明确 | 中：寻租机会可经其他路径产生 | 中 |
| M1→M2 | 高：政权宣传能力（Z）可独立激活外敌叙事，绕过M1 | 中：政权可能在制裁前已启动资源集中 | 高：移除此箭头主链即断裂 | 弱 |
| M2→Y | 低：资源控制直接支撑政权巩固，无明显共因 | 低：控制先于巩固，顺序成立 | 中：政权巩固还可依赖镇压能力等其他路径 | 中 |

最弱箭头：M1→M2（高第三变量风险 + 高稳健性风险）
必须画进图里：政权宣传能力作为M1→M2旁的调节变量

模块B 布局建议：
- 调节变量"制裁强度"标注在X→M1箭头旁
- "政权宣传能力"从文字说明升级为图中调节变量（标在M1→M2旁）
- "中产阶级瓦解"标为问号节点，位于M1与M2之间

模块C 最严重缺失：
- 缺失负案例（MAR）：3个案例均为制裁未能撼动政权，缺乏制裁成功的对照；可通过增加乌克兰2014等案例补救
- 缺失反事实（MNAR潜在风险）：无法说明若制裁不实施，威权政权是否同样会巩固；建议在正文中明确处理

综合结论：
当前最紧迫的补救任务：M1→M2箭头需补充时间顺序证据（档案或访谈），并将政权宣传能力纳入图中
可直接进入绘图的部分：X→M1 和 M2→Y 已足够稳健，可先定稿
```
