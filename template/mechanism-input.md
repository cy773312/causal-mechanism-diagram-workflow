# 机制文字准备模板

在开始 Step 1 之前，请按以下模板准备你的机制文字段落。完整的输入有助于 AI 更准确地识别主链和辅助因素。

## 模板

```
【研究问题】
（一句话说明你的研究问题，例如：为什么A导致了B？）

【机制段落】
（一段或几段文字，描述从原因X到结果Y之间的因果传导过程。
 请包含以下要素：
 - 初始条件或触发因素（X）
 - 中间传导过程（M1, M2, ...）
 - 最终结果（Y）
 - 如果存在，也请说明机制成立的条件、影响强弱的因素、
   以及其他可能的解释）

【额外说明（可选）】
- 研究范围（案例、时间、地区）
- 材料来源
- 你认为需要注意的特殊情况
```

## 写作提示

1. **使用因果连接词**："导致""引发""促使""进而""从而""推动"——这些词帮助识别机制节点
2. **区分条件与过程**："在……前提下""只有当……"通常引入背景条件；"但如果""当……时更强"通常引入调节变量
3. **明确起点和终点**：你的 X 是什么（初始条件/触发因素）？你的 Y 是什么（你想解释的现象）？
4. **不需要完整到可以发表**：草稿即可，Step 1 会帮助结构化

## 示例

```
【研究问题】为什么经济制裁有时反而强化了目标国的威权政权？

【机制段落】
经济制裁造成目标国经济稀缺性，使精英通过管控稀缺品获得寻租空间。
精英利益与政权绑定后，政权借外敌叙事集中经济部门控制，资源控制权
集中使政权具备更强的反对派压制与忠诚购买能力。这一机制在威权体制
已初步建立的国家更为明显。制裁强度会影响传导效果，反对派原有组织
能力也会调节机制的强弱。

【额外说明】
研究范围：中等规模威权国家，2000-2020年
材料来源：政府公报、国际组织报告
```
